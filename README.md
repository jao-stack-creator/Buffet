# Catálogo – Ineida Palhano Decorações

Site estático (HTML/CSS/JS, sem build). Abra `index.html` ou publique a pasta em qualquer hospedagem (Netlify, Vercel, GitHub Pages, Cloudflare Pages).

- **Produtos e preços:** array `CATEGORIAS` em `app.js`
- **Fotos:** pasta `img/` (mesmo nome usado em `i:` no `app.js`)
- **WhatsApp:** constante `WHATSAPP` no topo do `app.js`
